# Известные ограничения

Эта глава ведётся, а не дописывается: в ней то, чего ASR Hub **сейчас** не делает или что не проверено, — коротко и с обходным путём. Сделанное уходит отсюда в журнал изменений (`CHANGELOG.md` в корне проекта); планы и оценки объёма — в главе [33. Что доделать и улучшить](33-roadmap.md).

Состояние на версию 3.1.37.

## Не проверено на живом оборудовании

| Что | Чем проверено | Что это значит на деле |
|---|---|---|
| Asterisk 16–22 и FreePBX 16–17 с настоящим транком | подменные станции в тестах: AMI (в том числе TLS, вход по MD5, события очередей), журнал CDR, `queue_log`, диалплан, AudioSocket, SIP-телефон контроля качества | первую станцию подключайте с разделом «АТС» → «Разбор» и суточной сверкой «станция ↔ архив»: она покажет потери в первые же сутки |
| Раздельные дорожки `MixMonitor(…,r()t())`, код «не записывать» (`applicationmap`) | сценарий отправки, приём двух файлов и собранные файлы — в тестах; сам диалплан — по документации Asterisk | проверьте одной пробной станцией: в карточке звонка запись должна быть стерео, а код — останавливать запись |
| Установка и клиент для Windows (PowerShell) | разбор сценариев и проверки по тексту | установка на Windows Server — с присмотром; `-Pinned` повторяет `--pinned` из bash |
| Сборка образа Docker | файл образа и Compose разбираются в проверках; ночной прогон CI собирает образ minimal на процессоре — здесь не собирался | образ с видеокартой — на своей машине: `docker compose build` |
| Настоящие движки распознавания, синтез по образцу голоса (XTTS), языковая модель | демонстрационный движок, подменная команда синтеза, заглушка модели | качество и скорость — на своём оборудовании; см. главы [03](03-models.md) и [35](35-ai-analytics.md) |
| Пул видеокарт и процесс на воркер на настоящих картах | демонстрационный движок, имена устройств `cuda:0`/`cuda:1` без карт | первый запуск с `gpu_devices` — посмотрите в разделе «Мониторинг» на графиках нагрузки, что вторая карта работает |
| Распознавание автоответчика и голосовые ответы на живых звонках | разговор без сети со сценарием звука в тестах | включите `qc_amd` и `voice_answers` на одной группе и послушайте записи опросов (`qc_record`) |
| SIP по TLS и SRTP у телефона опросов | шифр — векторы RFC 3711 и libsrtp байт в байт; разговор — мини-АТС по TLS в тестах | первый пробный опрос с `qc_sip_transport: tls` и `qc_srtp` — на тестовом номере |
| Служба синтеза XTTS | подменная библиотека Coqui в тестах | прослушайте фразу группы кнопкой ▶ (голос опроса); журнал сервера пишет «Служба синтеза готова» |

## Сервер

| Ограничение | Обходной путь |
|---|---|
| В режиме `worker_isolation: thread` (по умолчанию) зависший внутри библиотеки вызов движка не прерывается: поток и его память живут до перезапуска | `worker_isolation: process` — процесс завершается вместе с памятью; цена — своя копия модели на воркер |
| Карта по свободной памяти (`gpu_pick: free_memory`) выбирается при старте задания: две модели, пришедшие разом, могут выбрать одну карту | число воркеров — кратно числу карт; тяжёлым моделям — явная карта в пресете |
| Близнецы в очереди (та же запись, те же настройки, тот же владелец) ждут идущего; близнец упал — второе задание распознаётся обычным порядком | дедупликация выключается параметром `deduplicate_jobs` |
| Кеш сводного отчёта аналитики — 30 с; изменения заданий на соседнем сервере над общей базой видны с этой задержкой | — |
| События заданий соседнего сервера над общей базой доходят опросом раз в секунду; прогресс — по базе, не чаще отметки хода задания | — |
| Цепочка хешей журнала доступа ловит правку и вырезанные строки, но не отрезанный хвост и не замену базы целиком | `audit_syslog` — копия строк во внешний журнал |
| Пароль копий шифрует только копию, уходящую командой «после копии»; копии в каталоге копий открыты | каталог копий — на отдельном диске с правами только для службы |
| Команда «после копии» задаётся только в файле настроек | так задумано: запуск программ на сервере — не право администратора приложения |
| Проверка типов (mypy) — без строгого режима: словари задания и звонка — `dict[str, Any]`, их поля не проверяются | — |

## Телефония

| Ограничение | Обходной путь |
|---|---|
| Отрезки записи по участникам разговора с переводом точны по мостам и событиям перевода только там, где станция их отдаёт (AMI с классом `call` или журнал CEL); без них — по времени ног CDR (секунды). События мостов и перевода, отображение CEL и `Local`-каналы очередей проверены на подменной станции, не на живой. «Разговоров» у сотрудника считает запись за добавочный записанной ноги — участие в переводах идёт отдельным столбцом | карточка записи («Кто говорил когда»), столбец «С переводом» в разрезах по сотрудникам, `GET /api/jobs/{id}/agents` |
| Живой разговор двух людей — рецептом «шпиона» (ChanSpy через Local-канал → AudioSocket) из раздела «Asterisk: диалплан»; на живой станции не проверялся, ARI ExternalMedia нет | распознавание записи после разговора (диалплан, агент) |
| События очередей из AMI пишут время приёма, если на станции не включено `timestampevents` | `timestampevents = yes` в `manager.conf` |
| Сверка «станция ↔ архив» не делается для AMI: независимого источника нет | для станций с AMI — журнал CDR как второй источник сверки |
| Самообновление агента — только по `auto_update` и только со сверкой sha256 | обновление установщиком |
| Докачка записей частями — у агента 3.1.35 и сервера 3.1.35; сценарий отправки из диалплана (`asrhub-dialplan`) и приём по ссылке шлют запись целиком | для больших записей из диалплана — поднять `client_max_body_size` у прокси; агент докачивает сам |
| Код «не записывать» в разговоре — через `features.conf`; через ARI с правом управления — нет | поле «Код «не записывать»» в разделе «Asterisk: диалплан» |

## Контроль качества

| Ограничение | Обходной путь |
|---|---|
| SRTP — только с ключами в SDP (SDES); DTLS-SRTP и MIKEY нет | SDES — вместе с SIP по TLS (`qc_sip_transport: tls`) |
| Автоответчик узнаётся по длине первой реплики и гудку голосовой почты, а не моделью; голосовой ответ — по словам и числам, без понимания фразы | `words` у вопроса «да/нет»; запись опроса для разбора спорных |
| Голос синтеза в установку сервера не входит; служба синтеза держит модель XTTS в памяти видеокарты, пока идут опросы | `bash scripts/models.sh voice ru_RU-irina-medium` — Piper с русским голосом одной командой; `qc_tts_service: false` — модель XTTS на фразу, память свободна |
| Входящий опрос узнаёт оператора только по заголовку SIP от станции (`X-ASRHub-Ext`, `X-ASRHub-Call`); рецепт перевода на живой станции не проверялся | обратный звонок — как раньше |
| Предел линий станции узнаётся по «занято» при своих же идущих звонках, а не спрашивается у станции | `qc_parallel` — не больше `call-limit` номера |

## Веб-интерфейс

| Ограничение | Обходной путь |
|---|---|
| В политике содержимого остаётся `'unsafe-inline'` для стилей: на нём держатся полосы и графики | исполнить что-то через стиль нельзя; скрипты — только файлами с сервера |
| Сортировка по столбцу — строк на экране, кроме «Результатов» (там — весь список на сервере); в адрес попадают период и отбор шести разделов, но не поля поиска «Результатов» | ссылка на карточку записи (`#jobs/<id>`) есть |
| Таблица на месте обновляется в «Очереди», «Результатах» и журнале звонков; остальные разделы при обновлении собирают таблицу заново | — |
| Интерфейс только на русском | — |
