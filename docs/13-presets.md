# Готовые наборы настроек

Пресет задаёт только те параметры, которые отличаются от значений по умолчанию. Это удобная отправная точка: возьмите ближайший к вашей задаче, прогоните десяток типовых файлов и правьте отдельные параметры.

Применить пресет можно тремя способами: в веб-интерфейсе на вкладке «Транскрибация», командой `POST /api/presets/<id>/apply` (меняет настройки сервера) или передав те же значения в поле `settings` конкретного задания.

## Русский: максимальная точность

**Идентификатор:** `ru-accuracy`

GigaAM v3 RNNT с готовой пунктуацией, широкий луч, аккуратная нарезка по VAD. Самый точный вариант для русского языка из доступных свободных моделей.

- **Сценарий:** Протоколы совещаний, юридические записи, интервью для публикации
- **Требования к железу:** GPU от 8 ГБ либо CPU от 8 ядер (медленнее примерно в 10 раз)
- **Чего ожидать:** RTF около 0.10–0.15 на RTX 3060; WER на чистой речи менее 3 %

| Параметр | Значение | Что делает |
|---|---|---|
| Движок (`engine`) | `gigaam` | Программная обвязка, которая исполняет модель |
| Модель (`model`) | `gigaam-v3-e2e-rnnt` | Конкретный набор весов |
| Язык (`language`) | `ru` | Язык записи в формате ISO 639-1 |
| Ширина луча (beam size) (`beam_size`) | `8` | Сколько вариантов расшифровки модель держит одновременно и сравнивает между собой |
| Каскад температур при неудаче (`temperature_fallback`) | `True` | Штатный механизм спасения |
| Включить детектор речи (`vad_enabled`) | `True` | Перед распознаванием запись разбирается на участки речи и тишины; в модель подаются… |
| Реализация VAD (`vad_backend`) | `silero` | silero — нейросетевой детектор, 2 МБ, лицензия MIT, обучен на корпусе из 6000+ языков… |
| Порог детектора речи (`vad_threshold`) | `0.45` | Вероятность, выше которой фрагмент считается речью |
| Минимальная тишина для разрыва (`vad_min_silence_ms`) | `700` | Сколько тишины должно пройти, чтобы речевой участок считался законченным |
| Максимальная длительность фрагмента (`vad_max_speech_s`) | `22.0` | Верхний предел длины одного речевого фрагмента |
| Поля вокруг речи (`vad_speech_pad_ms`) | `300` | Сколько миллисекунд звука добавить до и после найденного речевого участка |
| Нормализация громкости (`audio_normalize`) | `True` | Приводит громкость записи к целевому уровню фильтром loudnorm (стандарт EBU R128) |
| Фильтр низких частот (`audio_highpass_hz`) | `80` | Срезает частоты ниже указанной |
| Обрезать тишину по краям (`audio_trim_silence`) | `True` | Удаляет тишину в начале и конце файла до всех остальных этапов обработки |
| Размер пакета (`batch_size`) | `8` | Сколько фрагментов аудио обрабатывать одновременно |
| Пословные таймкоды (`word_timestamps`) | `True` | Время начала и конца каждого слова, а не только сегмента |
| Оценка уверенности (`include_confidence`) | `True` | Добавляет к сегментам и словам числовую оценку уверенности модели |
| Восстанавливать пунктуацию (`punctuation_enabled`) | `False` | Расставляет знаки препинания и заглавные буквы, если модель распознавания выдаёт «сырой»… |
| Нормализация чисел и дат (`itn_enabled`) | `False` | Обратная текстовая нормализация: «двадцать пять процентов» превращается в «25 %»… |
| Склеивать короткие сегменты (`merge_short_segments`) | `True` | Объединяет соседние сегменты одного говорящего, если они короче установленного предела |
| Разбиение на абзацы (`paragraph_mode`) | `speaker` | none — сплошной текст |
| Форматы выгрузки (`output_formats`) | `['txt', 'json', 'docx', 'srt']` | txt — чистый текст |

**Как применить**

```bash
curl -X POST http://сервер:8080/api/presets/ru-accuracy/apply \
  -H "X-API-Key: ваш_ключ"
```

- **Сценарий:** Тысячи файлов, важна пропускная способность
- **Требования к железу:** GPU от 12 ГБ
- **Чего ожидать:** RTF около 0.03–0.05 на RTX 3090; WER на чистой речи около 3–4 %

## Колл-центр и телефония

**Идентификатор:** `callcenter`

T-one оптимизирована именно под телефонию и обходит на ней все остальные свободные модели. Разделение по каналам даёт безошибочную атрибуцию реплик — точнее любой диаризации.

- **Сценарий:** Записи разговоров 8 кГц, часто стерео с разделением по каналам
- **Требования к железу:** CPU от 4 ядер и 8 ГБ RAM; GPU не обязателен
- **Чего ожидать:** WER на колл-центре около 8.6 %; работает в реальном времени на CPU

| Параметр | Значение | Что делает |
|---|---|---|
| Движок (`engine`) | `tone` | Программная обвязка, которая исполняет модель |
| Модель (`model`) | `tone-ru` | Конкретный набор весов |
| Язык (`language`) | `ru` | Язык записи в формате ISO 639-1 |
| Сведение каналов (`audio_channels`) | `split` | mono — свести все каналы в один (стандарт для ASR) |
| Частота дискретизации (`audio_sample_rate`) | `16000` | Частота, к которой приводится звук перед подачей в модель |
| Нормализация громкости (`audio_normalize`) | `True` | Приводит громкость записи к целевому уровню фильтром loudnorm (стандарт EBU R128) |
| Фильтр низких частот (`audio_highpass_hz`) | `100` | Срезает частоты ниже указанной |
| Включить детектор речи (`vad_enabled`) | `True` | Перед распознаванием запись разбирается на участки речи и тишины; в модель подаются… |
| Порог детектора речи (`vad_threshold`) | `0.4` | Вероятность, выше которой фрагмент считается речью |
| Минимальная длительность речи (`vad_min_speech_ms`) | `200` | Речевые участки короче указанной длительности отбрасываются как случайные звуки — щелчки… |
| Минимальная тишина для разрыва (`vad_min_silence_ms`) | `400` | Сколько тишины должно пройти, чтобы речевой участок считался законченным |
| Разделять по говорящим (`diarization_enabled`) | `False` | Определяет, кто и когда говорит, и размечает реплики метками «Говорящий 1», «Говорящий 2» |
| Имена говорящих (`speaker_names`) | `Оператор, Клиент` | Список имён через запятую, подставляемых вместо меток «Говорящий 1», «Говорящий 2» в… |
| Восстанавливать пунктуацию (`punctuation_enabled`) | `True` | Расставляет знаки препинания и заглавные буквы, если модель распознавания выдаёт «сырой»… |
| Нормализация чисел и дат (`itn_enabled`) | `True` | Обратная текстовая нормализация: «двадцать пять процентов» превращается в «25 %»… |
| Склеивать короткие сегменты (`merge_short_segments`) | `False` | Объединяет соседние сегменты одного говорящего, если они короче установленного предела |
| Разбиение на абзацы (`paragraph_mode`) | `speaker` | none — сплошной текст |
| Форматы выгрузки (`output_formats`) | `['json', 'txt', 'csv']` | txt — чистый текст |
| Записывать текст в журнал (`log_transcript_text`) | `False` | Сохранять ли распознанный текст в журнале сервера |

## Совещание с несколькими участниками

**Идентификатор:** `meeting`

Распознавание с разделением по говорящим и разбиением на абзацы по сменам реплик. Результат сразу пригоден для протокола.

- **Сценарий:** Записи планёрок, интервью, круглых столов
- **Требования к железу:** GPU от 12 ГБ (распознавание плюс диаризация)
- **Чего ожидать:** Время обработки примерно в 1.5 раза больше, чем без диаризации

| Параметр | Значение | Что делает |
|---|---|---|
| Движок (`engine`) | `gigaam` | Программная обвязка, которая исполняет модель |
| Модель (`model`) | `gigaam-v3-e2e-rnnt` | Конкретный набор весов |
| Язык (`language`) | `ru` | Язык записи в формате ISO 639-1 |
| Ширина луча (beam size) (`beam_size`) | `5` | Сколько вариантов расшифровки модель держит одновременно и сравнивает между собой |
| Включить детектор речи (`vad_enabled`) | `True` | Перед распознаванием запись разбирается на участки речи и тишины; в модель подаются… |
| Порог детектора речи (`vad_threshold`) | `0.35` | Вероятность, выше которой фрагмент считается речью |
| Минимальная тишина для разрыва (`vad_min_silence_ms`) | `600` | Сколько тишины должно пройти, чтобы речевой участок считался законченным |
| Поля вокруг речи (`vad_speech_pad_ms`) | `300` | Сколько миллисекунд звука добавить до и после найденного речевого участка |
| Нормализация громкости (`audio_normalize`) | `True` | Приводит громкость записи к целевому уровню фильтром loudnorm (стандарт EBU R128) |
| Фильтр низких частот (`audio_highpass_hz`) | `80` | Срезает частоты ниже указанной |
| Разделять по говорящим (`diarization_enabled`) | `True` | Определяет, кто и когда говорит, и размечает реплики метками «Говорящий 1», «Говорящий 2» |
| Метод диаризации (`diarization_backend`) | `pyannote` | pyannote — эталон качества, любое число говорящих, требует токена Hugging Face и принятия… |

| Привязывать говорящего к каждому слову (`diarization_assign_words`) | `True` | Определять говорящего не только для сегмента целиком, но и для каждого слова |
| Пословные таймкоды (`word_timestamps`) | `True` | Время начала и конца каждого слова, а не только сегмента |
| Метки говорящих в тексте (`include_speaker_labels`) | `True` | Добавлять имя или номер говорящего перед каждой репликой в текстовых форматах |

| Минимальная длина сегмента (`min_segment_duration_s`) | `1.5` | Сегменты короче указанного присоединяются к соседнему при склейке |
| Разбиение на абзацы (`paragraph_mode`) | `speaker` | none — сплошной текст |
| Удалять слова-паразиты (`remove_filler_words`) | `True` | Убирает из текста междометия и заполнители пауз: «э-э», «ну», «типа», «как бы», «short»… |
| Краткое содержание (`summary_enabled`) | `True` | Формирует сводку по транскрипту: ключевые темы, решения, задачи |
| Форматы выгрузки (`output_formats`) | `['docx', 'json', 'txt']` | txt — чистый текст |

## Whisper: устойчивый режим

**Идентификатор:** `whisper-robust`

Полный набор мер против галлюцинаций: VAD, отключённый перенос контекста, каскад температур, словарный фильтр и пропуск длинной тишины.

- **Сценарий:** Записи плохого качества, шум, длинные паузы, музыка
- **Требования к железу:** GPU от 8 ГБ либо CPU с int8
