# Пакеты, которые ставили прежние версии ASR Hub и которые больше не нужны.
#
# Установка, обновление и команды models.sh / models.ps1 с движками снимают
# их сами — но только при двух условиях:
#
#   * пакета нет ни в одном списке требований. Вернулся в требования —
#     значит, снова нужен, а эта строка устарела; снимать его нельзя;
#   * на него не опирается ни один оставшийся пакет. Если держатся только
#     пакеты из этого же списка, которые снимаются вместе с ним, — можно.
#
# Всё прочее лишнее обновление только называет и предлагает удалить: откуда
# оно взялось, знает тот, кто его ставил, а не мы.
#
# Зачем список, а не «удалить всё, чего нет в требованиях»: окружение
# сервера — наше, но руками в него ставят и своё, отладчик или профилировщик,
# и молча сносить чужое — хуже, чем напоминать о своём.
#
# Одно имя на строку, как его пишет pip. После «#» — когда появился и почему
# снят. Пакет, который приехал вместе со снимаемым как его часть, тоже
# перечисляется: иначе он переживёт хозяина и всплывёт в следующей проверке.
