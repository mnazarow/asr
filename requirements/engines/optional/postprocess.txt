# Необязательная часть движка postprocess: нормализация чисел от NeMo.
#
# Требует pynini, а тот собирается из исходников: готовых колёс под свежие
# версии Python нет, и без компилятора C++ установка не проходит. Ронять из-за
# этого весь движок — значит остаться и без расстановки знаков препинания,
# ради которой его чаще всего и ставят.
#
# Без этого пакета нормализация чисел не пропадает: сервер берёт rus2num, а
# если нет и его — встроенную русскую нормализацию (целые до миллиардов и
# проценты). NeMo точнее на датах, деньгах и порядковых числительных.
