# Необязательная часть движка postprocess: нормализация чисел от NeMo.
#
# Без неё движок работает: сервер берёт rus2num, а если нет и его — встроенную
# русскую нормализацию (целые до миллиардов и проценты). NeMo точнее на датах,
# деньгах и порядковых числительных.
#
# pynini прибит внутри nemo-text-processing к версии 2.1.6.post1, у которой нет
# готового колеса под свежие Python: pip уходит собирать её из исходников и
# упирается в заголовки OpenFst нужной версии, которых в дистрибутиве обычно
# нет. У 2.1.7 колесо есть — поэтому ставим её отдельно, а сам
# nemo-text-processing идёт спутником с --no-deps (иначе его жёсткая привязка
# вернула бы сборку). Связка проверена на Python 3.14: «двадцать пять
# процентов» → «25 %», «тысяча двести рублей» → «1200 руб.».
pynini>=2.1.7

# То, что nemo-text-processing импортирует при загрузке. Список перечислен
# руками, потому что сам пакет ставится без зависимостей.
regex
tqdm
joblib
wget
wrapt
sacremoses
inflect
pandas
# Колёс под свежие Python у этих двух нет, но собираются они за секунды —
# в отличие от pynini, которому нужен OpenFst.
editdistance
cdifflib

# Лёгкая пунктуация: RUPunct в ONNX, 29 МБ вместо 711, работает на процессоре
# и не занимает видеопамять. onnxruntime — один из немногих речевых пакетов, у
# которого есть колёса под свежие Python, поэтому вариант доступен там, где
# torch поставить нельзя.
#
# Здесь именно голый onnxruntime, а не optimum, хотя через него это три строки.
# `optimum-onnx` прибит к transformers младше 4.58, а движкам распознавания
# нужен свежий: на рабочем сервере это разошлось в первый же день —
# «optimum-onnx 0.1.0 has requirement transformers<4.58.0, but you have
# transformers 5.17.0». Такая несовместимость обычно не валит запуск, а
# всплывает потом необъяснимой ошибкой загрузки модели.
onnxruntime>=1.18

# Откуда забираются веса модели, когда рядом их нет. Ставится и сам по себе
# вместе с transformers, но здесь он нужен без него — на сервере, где
# пунктуация единственное, ради чего вообще трогают хранилище моделей.
huggingface-hub>=0.24
