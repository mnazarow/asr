# ── protobuf ────────────────────────────────────────────────────────────────
# NeMo объявляет protobuf~=5.29.5 и при установке утаскивает окружение на
# 5.29.6. Оставлять его там нельзя: googleapis-common-protos (приезжает с
# pyannote.audio ради диаризации) собран генератором 6.33.5, а protobuf
# отказывается загружать код, сгенерированный версией новее рантайма, — не
# предупреждением, а исключением при импорте:
#
#   VersionError: Detected incompatible Protobuf Gencode/Runtime versions
#   when loading google/rpc/status.proto: gencode 6.33.5 runtime 5.29.6.
#
# То есть диаризация ломается наглухо. Обратное направление безопасно и
# проверено на живых пакетах: рантайм 7.36.1 загружает код, сгенерированный
# 5.x, без единого замечания — protobuf запрещает только «рантайм старше
# генкода». Поэтому пин NeMo мы сознательно перешагиваем: он
# перестраховочный, а альтернатива — сломанный движок.
protobuf>=6.33.5
